SciPanel

Figure Panel Assembly
PsAi

SciPanel is a Photoshop/Illustrator CEP plugin focusing on layout, alignment, distribution, and annotation. It helps researchers quickly and accurately organize and annotate figures for scientific publications.

Interface Overview

Key Features

Resize to Guide
Resize layers to nearest guides.
Match Size
Match the size of selected layers to a target layer.
Resize to Exact Size
Resize layers to an exact pixel size.
Align to Anchor Object
Align selected layers to an anchor object, similar to Illustrator's Align to Key Object.
Align (Consider Linked Layers)
Align layers while keeping linked layers grouped together as a unit.
