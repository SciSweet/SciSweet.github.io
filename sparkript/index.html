Sparkript

Every SciSuite plugin includes a Custom Scripts section with assignable button slots. You can add more slots, assign any Photoshop/Illustrator script to a button, rename it, set a custom color and icon, and run it with a single click. This page collects scripts shared by the community — download one and assign it to your panel.

How It Works

1

Pick a Slot

Every plugin panel has a Custom Scripts section with 8 empty button slots ready to use. Need more? Click the "+" button at the bottom to add extra slots.

2

Assign a Script

Click a slot or right-click and choose "Assign Script..." to load a .jsx/.jsxbin script. Once assigned, the first few characters of the script name are automatically displayed on the button. You can also rename it, set a custom color, or replace the label with a 36×36 PNG/SVG icon.

3

One-Click Run

Click the button to run the script instantly. Right-click for options: reveal in Explorer, clear assignment, or remove the slot.
